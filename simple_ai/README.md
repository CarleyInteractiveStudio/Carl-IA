# Simple Rule-Based AI

This is the first version of a simple, rule-based AI assistant. It's built with basic Python and does not require any external libraries.

## How to Run

1.  Navigate to the `simple_ai` directory in your terminal.
2.  Run the application with the following command:

    ```bash
    python main.py
    ```

3.  Type your message and press Enter.
4.  To exit, type "adios".
