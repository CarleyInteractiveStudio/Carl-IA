# Carl AI - Ultra Modern Chat Interface

Carl AI is a premium, high-performance chat interface built with a focus on cutting-edge design, fluid animations, and a sophisticated Glassmorphism aesthetic.

## ✨ Features

- **Glassmorphism Design:** Real-time background blur and translucent surfaces for an immersive experience.
- **Fluid Animations:** Powered by Framer Motion for smooth transitions and state changes.
- **Deep Color Palette:** A sophisticated mix of Dark Forest Green, Deep Blue, and Vibrant Yellow accents.
- **Hugging Face Ready:** Built-in structure to connect with Hugging Face Inference API.
- **Modern Tech Stack:** React, TypeScript, Tailwind CSS, Lucide Icons.

## 🚀 Getting Started

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Configure your Hugging Face Token:**
   Open `src/App.tsx` and replace `"TU_TOKEN_AQUI"` with your actual Hugging Face API token.

3. **Run the development server:**
   ```bash
   npm run dev
   ```

## 🎨 UI/UX Philosophy

The interface is designed to surpass contemporary standards (like Microsoft's designs) by focusing on:
- **Depth:** Multiple layers of translucent materials.
- **Motion:** Constant, subtle background animations to create a "living" interface.
- **Typography:** Bold, high-contrast typography for better readability and a premium feel.
